# tw-earnings｜台股財報公告追蹤

追蹤台灣上市、上櫃公司每季財報公告，自動整理**毛利率**與**營業利益率**，並標出近 8 季的新高、新低。

網站：<https://htnvt241.github.io/tw-earnings/>

> 資料僅供參考，不構成投資建議。數字可能有誤差或延遲，請以公開資訊觀測站公布的財報為準。

## 功能

- **財報期間**：可選擇不同季別，預設為最新有公告的一季。
- **單季／累計**：單季是該季單獨的數字；累計是年初到該季末的合計（只有近期公告的季別才有）。
- **毛利率、營業利益率**，以及**較去年同期**、**較上季**的變化（百分點，紅色上升、綠色下降）。
- **毛/營新高低標記**：近 8 季（含當季）創新高或新低，以單季比較，當季須嚴格高於（低於）前 7 季，8 季資料齊全才判斷，金融保險業不判斷。
  - 毛利率新高＝黃色空心圈，營益率新高＝橙色空心圈，兩率皆新高＝紅色實心圓
  - 毛利率新低＝藍色空心圈，營益率新低＝深綠色空心圈，兩率皆新低＝亮綠色實心圓
- **趨勢圖**：點公司旁的折線圖示，開啟近 8 季的毛利率與營業利益率趨勢圖與數值表，可拖曳、縮放，折點創新高圈紅圈、新低圈綠圈。
- **篩選與搜尋**：依新高低篩選，可用代號或名稱搜尋，欄位可排序。
- 點整列可看原始公告的營業收入、營業毛利、營業利益（仟元）與公告主旨。

## 名詞說明

- 毛利率＝營業毛利（毛損）÷ 營業收入；營業利益率＝營業利益（損失）÷ 營業收入。
- 單季＝本季累計 − 上季累計。「≈」表示該單季數字由累計推算，上季金額來自 XQ 歷史資料，精度略低（實測誤差通常極小）。
- 「較早公告」表示重大訊息已查不到，改由損益表補上，沒有公告時間。
- 金融保險業沒有營業毛利，顯示「不適用」。

## 資料來源

| 來源 | 用途 | 更新特性 |
|---|---|---|
| 證交所 OpenAPI（重大訊息、綜合損益表） | 上市公司財報公告與數字 | 約隔天清晨更新前一天資料 |
| 櫃買中心 OpenAPI（重大訊息、綜合損益表） | 上櫃公司財報公告與數字 | 約下午更新前一天資料 |
| 公開資訊觀測站「即時重大訊息」 | 當天的財報公告，比 OpenAPI 早一天 | 當天資料，午夜重置 |
| XQ 匯出的近 12 季資料 | 歷史單季毛利率與營業利益率 | 手動匯出，不會自動更新 |

判斷是否為財報公告，一律以公告內容的「符合條款＝第 31 款」為準，不用主旨關鍵字。

## 運作方式

全部跑在 GitHub 上，不需要自己的伺服器：

1. **GitHub Actions** 依排程執行 Python 程式，抓資料後存成 JSON，自動提交回儲存庫。
2. **GitHub Pages** 把 `index.html` 當作網站，讀取 `data/` 裡的 JSON 顯示。

排程（台灣時間）：

- `update-earnings`：每 4 小時第 47 分鐘（台灣時間 02:47、06:47、10:47、14:47、18:47、22:47，抓官方 OpenAPI)。
- `update-mops`：每天 12:00、15:00、18:30、21:00、23:00，抓 MOPS 即時重大訊息。

兩個工作共用同一個排程群組，不會同時修改檔案。也可以在 Actions 分頁手動執行（Run workflow）。

## 檔案結構

```
index.html                      網站（純前端）
fetch_earnings.py               抓 OpenAPI，合併進 data/earnings.json
fetch_mops.py                   抓 MOPS 即時財報公告，補進 data/earnings.json
data/earnings.json              近期公告的累計金額、單季與公告時間
data/history.json               XQ 歷史單季毛利率與營業利益率
data/mops_seen.json             MOPS 已查詢過的公告紀錄（約保留 7 天）
.github/workflows/update.yml    OpenAPI 排程
.github/workflows/mops.yml      MOPS 排程
```

兩支 Python 程式都只用標準函式庫，不需要安裝套件。

## 已知限制

- 官方 OpenAPI 的重大訊息只保留最近一天，沒有歷史；損益表只有最新一季。
- `history.json` 來自 XQ 手動匯出，需要時再重新匯出更新；沒有 XQ 資料的公司（例如剛上市或新板公司）沒有歷史，也就沒有新高低標記。
- 某些公司的財報公告若在資料累積之前就發布，可能沒有公告時間，或暫時沒有資料。
- 資料來源的格式或網址若有調整，抓取可能失敗，Actions 會顯示警告或錯誤。

## 本機測試（選用）

程式可以用下載好的 JSON 檔案離線測試，不連網：

```
python fetch_earnings.py --file t187ap04_L.json --income-file t187ap06_L_ci.json \
  --tpex-file mopsfin_t187ap04_O.json --tpex-income-file mopsfin_t187ap06_O_ci.json
```

直接雙擊開啟 `index.html` 會因瀏覽器限制讀不到 `data/*.json`，請用 GitHub Pages 網址，或在資料夾內執行 `python -m http.server` 再開啟 `http://localhost:8000`。
